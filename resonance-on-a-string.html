Why it happens

The driver sends a wave down the string. The wave reflects at the fixed end and travels back. The round trip takes 2L ÷ v seconds.

If that time equals a whole number of driver periods, each returning wave arrives exactly in step with the next push. Every push adds energy, and the swing grows until damping removes energy as fast as the driver supplies it. At any other frequency the returning waves arrive out of step and mostly cancel the new ones.

fₙ = n · v ÷ 2L   (n = 1, 2, 3 …) For this string: f₁ = 24 ÷ (2 × 1.20) = 10.0 Hz At resonance λₙ = 2L ÷ n, so n half-wavelengths fit between the ends.

Run it in class

  1. Set the frequency to about 14 Hz. The driver works hard but the string barely moves.
  2. Press Still the string, then jump to the 1st harmonic. Watch the swing grow push after push.
  3. Step through harmonics 2 to 5 and have students count the loops each time.
  4. Ask for a prediction: what happens to f₁ if the string is shortened to 0.60 m? Then test it.
  5. Switch damping between light and heavy and compare the height and width of the peaks.
  6. Hide the predicted curve and run a sweep, so the class sees the curve appear from measurements.
