    Table of standard enthalpies of formation, ΔH°f (kJ/mol, 25 °C, 1 atm)

    Each substance shows its formation equation: 1 mol of the substance made from its elements in their standard states, so fractions such as ½O₂ can appear. Doubling the equation doubles ΔH°. For ions, values are measured relative to H⁺(aq) = 0, so H⁺(aq) and H₂(g) appear in the equation. Your own equations use this table. Values come from Wikipedia's “Standard enthalpy of formation” table (CRC Handbook and NIST data); a few common ions and liquids were added from the CRC Handbook. The ready-made reactions above use the book's rounded values (for example CO₂ = −394), so answers can differ by a few kJ. An element in its standard state (O₂, H₂, N₂, Cl₂, Br₂(l), I₂(s), C graphite, Fe, Al…) has ΔH°f = 0. The table is built into the page, so it works offline.

    Values follow the tables in Inspire Chemistry (Module 14) rounded as the book does; the “type any equation” tool uses the fuller ΔH°f table (Wikipedia/CRC). Worked examples follow the book's Analyze → Solve → Evaluate format. Answers are given to three significant figures.
